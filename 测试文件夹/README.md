# 车源录入助手（第一代）

Chrome Manifest V3 侧边栏插件，用于管理端车源录入的半自动辅助流程。

按“模拟操作/vehicle-full-flow.json”录制流程批量填写车源基础信息；图片、价格和提交由人工处理，但**人工提交成功后插件会自动进入下一条**，循环到全部完成。

## 支持能力

- 导入 `.csv`、`.xlsx`，以及部分管理系统导出的 HTML/XML 形式 `.xls`
- 固定模板 `.xlsx` 会按表头签名自动归一化成标准填表数据；完整 `Sheet2` 宽表（例如 `工作簿1(1)-原始备份.xlsx` 的 `Sheet2`）会先抽取出中间 10 列，再转换成标准填表数据
- 按“录制流程”字段顺序精准定位 `#myForm_vehicleType`、`#myForm_specInfo_brandId` 等控件填充
- 可选调用兼容 OpenAI Chat Completions 的 AI 接口，输出车型标准化建议（已有车型测试可跳过）
- 探测当前页面可见输入框、原生下拉、Ant Design 下拉/日期控件
- 批量录入状态机：`idle → filling → waitingManualSubmit → nextRow → done`
- 提交成功后自动推进下一行（三重兜底，详见下文）

## 不做的事

- 不自动新增品牌、车系、车型或配置库
- 不自动上传图片
- 不自动填写底价/售价（CSV 中的价格仅作为参考价展示）
- 不自动点击提交按钮（提交由人工点击）
- 不直接调用 `inventoryVehicleSubmit` 等提交接口

## 自动推进下一行机制

当前行填完后插件进入 `waitingManualSubmit` 阶段，等待人工：上传图片 → 填写底价/售价 → 点击提交。
提交成功后插件会自动进入下一条，触发方式按优先级：

1. **成功提示监听**：content script 通过 MutationObserver + 定时器检测页面“操作成功/提交成功/保存成功”等提示，立即发 `VA_SUBMIT_SUCCESS`。
2. **pagehide 兜底**：提交后页面跳转回列表页时，content script 会在 `pagehide`/`beforeunload` 瞬间（若已点过提交按钮且无校验错误）补发 `VA_SUBMIT_SUCCESS`，避免页面卸载导致消息丢失。
3. **URL 变化兜底**：sidepanel 监听 `chrome.tabs.onUpdated`，当 `waitingManualSubmit` 阶段检测到 tab 从新增页（`showPageModel=1`）跳到同源列表页，延迟 1.5s 确认后自动推进。

若以上三重兜底都漏掉，可点击侧边栏“我已提交，继续下一条”按钮手动推进。

## 安装方式

1. 打开 Chrome / Edge。
2. 进入 `chrome://extensions`。
3. 开启「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择本目录：`vehicle-upload-assistant`。
6. 打开管理端页面后，点击浏览器扩展图标，侧边栏会自动打开。

## 使用流程

1. 登录管理端（`test.forjtruck.com`），打开“车源管理 → 审核列表”页面。
2. 打开插件侧边栏。
3. 导入 CSV/Excel，或点击“加载录制流程示例”。
4. 如需要，填写 AI 配置并点击“AI 标准化”；已有车型测试可跳过。
5. （可选）点击“探测当前页面”/“生成缺失清单”，查看页面字段是否匹配。
6. 点击“开始/继续批量录入”。
7. 插件自动进入新增库存车页面，按录制流程填充当前行（车辆类型、是否带挂、车主手机号、VIN、车身颜色、表显里程、上牌日期、车籍所在地、停放地区、停放详细地址、车籍性质、过户信息、品牌、车系、车型、车辆描述）。
8. 在管理端页面人工处理：上传图片、填写/确认底价和售价、点击提交。
9. 提交成功后，插件自动进入下一条并重复填充；如未自动推进，点击“我已提交，继续下一条”。
10. 全部行提交完成后，插件显示“全部完成”。

## 推荐导入表头

```csv
车辆类型,品牌,车系,车型,子类,年款,VIN,发动机号,登记日期,里程,标题,颜色,排放标准,燃料类型,变速箱
```

可使用侧边栏里的“下载模板”生成模板文件。

## 本地 smoke test

1. 安装插件。
2. 在浏览器中打开 `samples/mock-admin.html`。
3. 侧边栏点击“加载示例”。
4. 点击“探测当前页面”。
5. 点击“生成缺失清单”。
6. 点击“填当前行”。
7. 确认 mock 页面中的车辆类型、品牌、车系、车型、VIN、发动机号、登记日期、里程、标题、颜色、排放、燃料、变速箱被填写或选择。

## 管理端注意事项

- 品牌、车系、车型通常是级联下拉：车辆类型 → 品牌 → 车系 → 车型。插件会按这个顺序填写，并在每一步后等待下一级选项加载。
- 复杂 Ant Design 下拉如果未找到完全匹配选项，插件会报告“请人工选择”，不会强行点击第一个选项。
- 如果页面没有暴露完整下拉选项，“缺失清单”会提示需要人工确认。
- 插件只处理当前活动标签页，使用当前浏览器登录态操作页面。
